# «В гостях у Тани» — карта переходов

## Основная навигация

- Комната (`#home`)
  - мольберт → Картины (`#paintings`)
  - камера на полке → Фотографии (`#photos`)
  - чемодан → Путешествия (`#travel`)
  - гардероб → Мой стиль (`#style`)
  - портрет Тани → Обо мне (`#about`)
  - письменный стол → Написать мне (`#contact`)
  - деловая карточка → Сотрудничество (`#collab`)
  - закрытый шкаф → Личное (`#personal`)
- Личное (`#personal`)
  - Любовные истории (`#love`) — открытый предпросмотр, продолжение закрыто
  - За кадром (`#behind`) — открытый предпросмотр, продолжение закрыто
- Все карточки галерей → модальный просмотр изображения, предыдущая/следующая, Escape для закрытия.
- На мобильных: меню-кнопка + нижняя панель из пяти основных разделов.

## Формы

- «Написать мне» и «Сотрудничество» валидируются в браузере.
- Отправка подготовлена через `window.TANYA_TELEGRAM_ENDPOINT`.
- Токен Telegram-бота в клиентский код не помещается. Нужен серверный/edge endpoint перед публикацией.
